# AnyTogether

**The online home of the AnyPS5 launchers** on macOS, Windows and Linux. Profiles, trophies,
friends, parties, voice chat, messages, share play, leaderboards, themes and downloads, at
[anytogether.kodla.agency](https://anytogether.kodla.agency). A kodla.agency project.

Players talk to each other directly (voice, share play and pads go peer-to-peer, encrypted); the
server introduces them and keeps what must be kept. Signing in is one tap. This branch holds the
plan only; there is no code here yet. Each document exists in English and in Turkish.

**macOS, Windows ve Linux'taki AnyPS5 launcher'larının online evi.** Profiller, kupalar,
arkadaşlar, partiler, sesli sohbet, mesajlar, birlikte oynama, liderlik tabloları, temalar ve
indirmeler;
[anytogether.kodla.agency](https://anytogether.kodla.agency) adresinde. Bir kodla.agency projesi.

Oyuncular birbirleriyle doğrudan konuşur (ses, birlikte oynama ve kol verisi şifreli olarak
oyuncudan oyuncuya gider); sunucu onları tanıştırır ve saklanması gerekeni saklar. Giriş tek
dokunuş. Bu branch'te yalnızca plan var, henüz kod yok. Her belge İngilizce ve Türkçe olarak
duruyor.
